# Sección de Recetas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar un sexto tab "Recetas" de solo lectura a la app `plan-alimentacion`, compartido entre Ángel y Gabriela, precargado con 5-6 recetas de ejemplo vía el script de seed existente.

**Architecture:** Mismo patrón que `variety/main` y `shopping/main`: un doc único `recipes/main` en Firestore con `{ list: Recipe[] }`, leído en tiempo real vía `onSnapshot` y renderizado en un tab nuevo (`RecetasTab.jsx`) con los mismos componentes (`Card`, `SectionTitle`, `Pill`) que ya usa el resto de la app.

**Tech Stack:** Vite, React 19, `firebase` (Firestore JS SDK), `firebase-admin` (script de seed), `lucide-react`.

## Global Constraints

- Solo lectura — sin UI de edición/borrado/alta (spec: "Fuera de alcance").
- `recipes/main: { list: Recipe[] }` con `Recipe = { title: string, tag: "Desayuno"|"Almuerzo"|"Merienda"|"Cena", ingredients: string[], steps: string[] }` (spec: "Modelo de datos").
- Reutilizar las 4 etiquetas de comida ya existentes (`MEAL_ICON` en `src/iconMap.js`) para `tag` — no crear un sistema de íconos nuevo (spec: "Modelo de datos").
- No se modifica `firestore.rules` — la regla wildcard existente ya cubre la colección nueva (spec: "Modelo de datos").
- Sin acordeón/colapso en el tab — todo el contenido de cada receta visible siempre (spec: "UI").
- Repo: `angelmeier10-fit/plan-alimentacion`, deploy automático a GitHub Pages en cada push a `main` (ya configurado, sin cambios necesarios en el workflow).

- [ ] **Step 1: Crear el componente**

```jsx
// plan-alimentacion/src/tabs/RecetasTab.jsx
import Card from "../components/Card.jsx";
import SectionTitle from "../components/SectionTitle.jsx";
import Pill from "../components/Pill.jsx";

export default function RecetasTab({ data, accent }) {
  return (
    <div style={{ display: "flex", flexDirection: "column", gap: 14 }}>
      <SectionTitle sub="Ideas para variar el menú">Recetas</SectionTitle>
      {data.map((recipe) => (
        <Card key={recipe.title}>
          <div style={{ display: "flex", alignItems: "center", justifyContent: "space-between", marginBottom: 10 }}>
            <div style={{ fontFamily: "'Fraunces', serif", fontSize: 17, fontWeight: 600 }}>
              {recipe.title}
            </div>
            <Pill accent={accent}>{recipe.tag}</Pill>
          </div>
          <div style={{ fontSize: 13, fontWeight: 600, color: "#6B6459", marginBottom: 4 }}>
            Ingredientes
          </div>
          <ul style={{ margin: "0 0 12px", paddingLeft: 18, fontSize: 14, lineHeight: 1.5 }}>
            {recipe.ingredients.map((ing) => (
              <li key={ing}>{ing}</li>
            ))}
          </ul>
          <div style={{ fontSize: 13, fontWeight: 600, color: "#6B6459", marginBottom: 4 }}>
            Preparación
          </div>
          <ol style={{ margin: 0, paddingLeft: 18, fontSize: 14, lineHeight: 1.5 }}>
            {recipe.steps.map((step) => (
              <li key={step}>{step}</li>
            ))}
          </ol>
        </Card>
      ))}
    </div>
  );
}
```

Nota: revisar `SectionTitle.jsx` y `Pill.jsx` antes de este paso para confirmar los nombres exactos de props (`sub` en `SectionTitle`, `accent` en `Pill`) — deben coincidir con cómo los usan `ComprasTab.jsx` y `FlexTab.jsx`, que ya están en el repo como referencia directa.
